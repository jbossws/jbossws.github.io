JBossWS-CXF 8.0.0.Final has been released. This release upgrades key security components — Apache CXF to 4.1.9 and WSS4J to 4.0.2 — resolving multiple CVEs, along with OpenSAML 5.2.3. It aligns with WildFly 41.0.1.Final and sets Java SE 17 as the minimum supported runtime.

See more details in [the last Blog post]({% post_url 2026-10-13-jbossws-800-release %})

Please try out this release, and let us know if you have any issues or questions.
